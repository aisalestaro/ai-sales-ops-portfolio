# 03. 社内ナレッジ検索 Bot・AI コンシェルジュ

## 課題
- 料金・導入手順・過去事例が Slack と Notion に散らばり、「担当者に聞かないと分からない」。営業・CS の時間が奪われる
- 顧客側も同じ。HP を見ても自社に当てはまる事例・プランが分からず、営業に聞くしかない

## 何を作るか決めた理由
- 社内の「聞かないと分からない」と、顧客の「聞かないと分からない」は同じ構造。**同じ RAG 基盤で両方を解く**

## 設計
- 社内向け：Slack・Notion の情報を取り込み、RAG で回答する営業アシスタント Bot
- 顧客向け：HP の AI チャット。事例・プランを自動提示し、FAQ 動画約30本へ誘導。Web・LINE・Slack から申し込みまで完結

## 実装
- Python／FastAPI／Firestore。Docker 化して GCP Cloud Run にデプロイ（Cloud Build・Secret Manager）
- 取り込みは差分更新。回答には出典（Notion ページ／Slack スレッド）を必ず付ける
- 顧客向けは問い合わせフォームと接続し、申し込み内容を案件管理 OS へ流す

## 検証
- 営業を介さない受注 **月10件**（AI チャット＋提案動画＋ステップメールの合算）
- 社内では「料金・導入手順の質問が Slack に飛んでこなくなった」。問い合わせ件数は定性的に把握

- **最初に外した仮説**: 「何でも答えられる Bot」。実際は回答範囲を絞り、分からないことは「担当者に繋ぐ」と答えさせてから信頼された

## 運用改善
- 回答の不正解は Slack の👎で収集 → 週次で取り込み対象と回答テンプレを修正

## 守り・責任分界
- 顧客向けは公開情報のみを回答範囲にする。料金・契約条件の確定は人。Secret は Secret Manager に置きコードに書かない
